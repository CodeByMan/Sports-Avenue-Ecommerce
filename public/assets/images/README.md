# Demo Image Assets

These image files are original, generated demonstration graphics for Sports Avenue.

- Fictional names only.
- No official club or league marks.
- No commercial product photography.
- No sponsor logos.
- No copied kit designs.

Regenerate them from the repository root with:

```bash
python3 scripts/generate-demo-assets.py
```

The generator requires Python 3 and Pillow. Generated files are covered by the repository MIT licence; see `THIRD_PARTY_NOTICES.md`.
